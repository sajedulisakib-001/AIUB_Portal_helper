GeoGebra Point Extractor

How to Use

1. Getting started

This extension reads the points currently on a GeoGebra applet and converts their coordinates into ready-to-use code. Before you start, make sure you actually have a GeoGebra page open in the active browser tab — the one with your graph, points, and shapes on it.

  1. Open the GeoGebra page in your browser.
  2. Click the extension's icon in the toolbar to open the popup.

The extension only works on pages where GeoGebra's applet is actually loaded. It won't do anything on a blank tab, Chrome's settings pages, or a page where GeoGebra hasn't finished loading yet.

2. Skipped points

The "Skipped points" box lets you list any point names you don't want included in the output, separated by commas. For example:

X,Y,X1,Y1

That's the default, and it's there because many GeoGebra constructions use points named X, Y, X1, Y1 as helper/reference points that you usually don't want in your final output. Add or remove names here as needed — you can leave it as the default if you're not sure.

Points that are hidden or disabled in GeoGebra (deselected in the algebra view) are always left out automatically — you don't need to list them here as well.

3. Get Data

Click the Get Data button. The extension scans every point currently defined in your GeoGebra file, in the order they appear in the algebra view, and turns each one into a line of coordinate code. Points are automatically grouped by the shape they belong to (using any text labels in your construction) and sorted in a sensible order.

The result appears in the big Output box, and the status line underneath tells you how many shapes and points were found.

4. Point naming

The extractor recognizes:

  • Plain letters: A, B, AB
  • Single-digit subscripts: A1, A_1, up through Z9

All of these count as valid points and get pulled into the output, sorted first by subscript number and then alphabetically within each group (so you'll see A, B, ... Z, A1, B1, ... Z9).

Known limit: points with a two-digit-or-higher subscript (A10 and beyond) are not currently guaranteed to be picked up. If your construction needs more than 10 points per letter (A, A1, A2 ... A9), name the extras differently — for example, a new letter — rather than relying on subscripts past 9.

A point is otherwise only excluded for one of two reasons: it's hidden/deselected in GeoGebra's algebra view, or its name is in the "Skipped points" box.

5. Copy the output

Once you have output, click Copy to copy the entire contents of the Output box to your clipboard. You'll see the button briefly change to "Copied!" to confirm it worked. From there you can paste it directly into whatever tool or code editor you're using.

6. Color picker

There are two ways to use it:

  • From the popup: click Pick Color from Screen, then click on any color anywhere on your screen — this works on any tab, and even outside the browser entirely (another app, an image, etc). This is the most reliable way to trigger it.
  • Keyboard shortcut: press Ctrl+Shift+U (Cmd+Shift+U on Mac) from anywhere in the browser, then click the color you want. You'll see a small notification confirm the color was copied.

Either way, the hex code of whatever you clicked on (like #ff5733) is copied to your clipboard automatically. Using the popup button also shows the value in the field below the button, in case you need to see it again.

If you press Escape or click somewhere that cancels the picker, nothing is copied — that's expected, just try again.

7. Reading the output

Each shape in the output looks something like this:

// Square
glColor3f(1.00, 0.34, 0.20);
glBegin(GL_POLYGON);
	glVertex2f(0.00, 0.00);//A
	glVertex2f(1.00, 0.00);//B
	glVertex2f(1.00, 1.00);//C
	glVertex2f(0.00, 1.00);//D
glEnd();
  • The comment line (// Square) comes from a text label in your GeoGebra construction, if you added one.
  • The color line appears only if that text label included a color tag, like Square-c(#FF5733).
  • Each vertex line is one point's coordinates, with the original point name as a trailing comment so you can trace it back.

8. Troubleshooting

Nothing shows up in Output:

  • Double check you're on the tab with the GeoGebra applet loaded — the extension reads the active tab.
  • Make sure your points are named in a way the extractor recognizes — see Point naming above.
  • Check that your points aren't all hidden/deselected in the GeoGebra algebra view, or all listed in "Skipped points."

Color picker doesn't do anything:

  • Using the popup button? Make sure you click the picker button itself first, then click the color you want — the picker only starts after that first click.
  • Using the keyboard shortcut and nothing happens? Chrome shortcuts sometimes get taken over by another extension or a system-level shortcut. Check chrome://extensions/shortcuts to confirm Ctrl+Shift+U is still assigned to this extension, or just use the popup button instead — it always works.
  • This feature needs a fairly recent version of Chrome; if it's still not working, try updating your browser.
